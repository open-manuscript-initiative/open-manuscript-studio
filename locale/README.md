# Studio translation catalogs

For the primary Studio interface locales, the PO catalogs are the editable source of truth:

- `en/studio.po` — English source language and default locale
- `de/studio.po` — German
- `hu/studio.po` — Hungarian
- `fr/studio.po` — French
- `it/studio.po` — Italian
- `es/studio.po` — Spanish
- `nl/studio.po` — Dutch
- `pl/studio.po` — Polish

Each primary catalog covers every key in the English reference across the shared Studio UI and research-module interfaces, including Transkribus. The `msgctxt` value is the stable translation key, `msgid` is the English source text, and `msgstr` is the localized text.

The JSON files under `src/i18n/locales/<locale>/studio.json` are generated runtime dictionaries. Do not edit them directly. The primary catalogs above are compiled by default with:

```sh
npm run i18n:po:compile
```

Development, build and test commands run this compilation before using the dictionaries. To compile every existing PO catalog, including locales still in the migration phase, use:

```sh
npm run i18n:po:compile -- --all
```

The JSON-to-PO export skips the primary catalogs above so it cannot overwrite the translator-maintained sources. Add or change shared UI strings in the catalogs, keep the same `msgctxt` key in each primary catalog, then run the compiler and tests. Research-module shell, panel and insertion copy is also stored in these catalogs under `/researchModules/`. Runtime components read the generated dictionary, and the matching JSON entries are generated by the same compiler.
