# Studio translation catalogs

For the primary Studio interface locales, the PO catalogs are the editable source of truth:

- `en/studio.po` — English source language and default locale
- `de/studio.po` — German
- `hu/studio.po` — Hungarian

Each catalog contains 1,361 translated strings across the shared Studio UI and research-module interfaces. The `msgctxt` value is the stable translation key, `msgid` is the English source text, and `msgstr` is the localized text.

The JSON files under `src/i18n/locales/{en,de,hu}/studio.json` are generated runtime dictionaries. Do not edit them directly. They are compiled from the PO catalogs by:

```sh
npm run i18n:po:compile
```

Development, build and test commands run this compilation before using the dictionaries. To compile every existing PO catalog, including locales still in the migration phase, use:

```sh
npm run i18n:po:compile -- --all
```

The JSON-to-PO export skips English, German and Hungarian so it cannot overwrite the primary source catalogs. Add or change shared UI strings in the catalogs, keep the same `msgctxt` key in all three, then run the compiler and tests. Research-module shell, panel and insertion copy is also stored in these catalogs under `/researchModules/`. Runtime components read the generated dictionary, and the matching JSON entries are generated by the same compiler.
