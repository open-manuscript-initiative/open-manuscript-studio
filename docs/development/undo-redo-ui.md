# Undo/redo header controls

The Studio header uses the conventional curved-arrow Undo and Redo icons. On mobile the icons are deliberately rendered at 21 px with a 2.5 px stroke and a minimum 2.6 rem touch target so that the controls remain recognizable even while disabled.

Disabled controls remain visibly gray rather than fading to near-invisibility. The buttons still expose localized accessible names and keyboard shortcut tooltips on pointer-capable devices.
