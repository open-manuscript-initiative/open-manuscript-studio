# Open Manuscript Studio 0.3.0-beta.11

Release preparation: **24 October 2026**. This release improves long-document editing responsiveness and reduces offscreen page-guide rendering while navigating. Published historical releases remain immutable.

## What changes for users

- **Live publication editor:** reuses line measurements for unchanged blocks and remeasures only affected content after edits.
- **Print navigation:** renders page guides for the visible area and a nearby buffer, reducing the decorative page elements painted for very long manuscripts.
- **Portable format:** the OMI manuscript format remains `OMI-SPEC-320@0.3.0`.

## Updating and deployment

The [Studio downloads page](https://openmanuscript.org/studio/) follows the current published GitHub release. After the release PR is merged, native build workflows produce packages from the merged commit. Google Play still requires a separate Android Release run from the merged `main`; its versionCode is derived from that run. iOS public distribution still requires Apple signing, provisioning and device/TestFlight validation.

No server migration is required.
