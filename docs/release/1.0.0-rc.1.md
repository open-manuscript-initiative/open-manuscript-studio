# Open Manuscript Studio 1.0.0-rc.1

**Source preparation, 4 November 2026. UNRELEASED / NO-GO. NOT an independently certified release.**

This stages the first 1.0 release candidate's package identities and publication
boundaries. It does not certify a candidate SHA, host, physical device or binary.
The RC must stay a GitHub prerelease and must not become the general updater's
`latest` release. Stable 1.0 requires a later, separate decision.

## Changes since beta.13

- Connection-pinned OJS/OMP/WebDAV transport and OIDC/JWKS verification,
  isolated PDF worker hardening, and production rollback checks.
- Unified continuous/frame layout, default A4 text frame, page styles,
  running headers, editable graphic placement and table improvements.
- Validation progress and per-check timing, retained manuscript semantics
  in PDF/HTML publication, and additional preservation regressions.

Draft-model self-assessments remain self-assessments. The portable manuscript
format remains **OMI-SPEC-320@0.3.0**; application 1.0 does not change it.

## Publication behavior

Ordinary main pushes and tag pushes build 1.0 RC/stable artifacts without
publishing. Explicit `candidate_only=true` remains available. A publication
attempt requires a main-branch manual dispatch and the exact version tag; the
existing reviewed-SHA, `APPROVE_1_0_RELEASE`, prior-build, 13-gate receipt,
artifact hash, E02 and strict Go/No-Go checks still apply unchanged.
