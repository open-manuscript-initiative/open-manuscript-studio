# Open Manuscript Studio 0.3.0-beta.2

Status: live collaboration beta  
Date: 2026-09-28  
Previous release: 0.3.0-beta.1

## Release purpose

This beta adds invitation-authorized live manuscript collaboration to the
existing Studio deployment. Authors can invite co-authors, invited users accept
their invitation in Studio, and all authorized participants edit the same
manuscript in real time. The rollout retains the existing single-node VPS
deployment and manuscript storage/data paths.

## Live collaboration and invitations

- Adds shared live editing using Yjs synchronization.
- Adds an in-Studio invitation inbox so authors can see and accept invitations
  without relying on an e-mail notification.
- Keeps manuscript access closed until the invited Studio account explicitly
  accepts; the server checks invitation ownership, expiry, replay and revocation.
- Shows each collaborator's display name and distinct color beside live cursors
  and remote selections.
- Persists shared updates and restores room state after reconnects using the
  single-node collaboration service.
- Leaves review change tracking in the peer-review workflow, separate from live
  co-editing.

## Architecture and compatibility

Collaboration authority remains server-owned. Only accepted, active manuscript
members can receive short-lived connection tickets. The persistent Yjs update
store is separate from the portable manuscript file. The production profile is
the existing single-node deployment; distributed deployment remains a later
architecture step.

No OMI schema, JSON envelope, container contract, API-v1 or import/export data
path changes are included. Existing OMI-SPEC-320@0.2.0 manuscripts need no
migration.

## Release gates

Before publication require green results for OMI Studio CI/CD, 1.0 Readiness,
CodeQL, PKP integration acceptance, Tauri desktop/mobile builds and the iOS
simulator smoke build. Android Play publication remains a separate explicit
Android Release workflow action.
