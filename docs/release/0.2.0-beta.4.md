# Open Manuscript Studio 0.2.0-beta.4

Status: cross-platform stabilization beta  
Date: 2026-09-21  
Next planned milestone: v1.0.0-rc.1

## Release purpose

0.2.0-beta.4 packages the development that was already available in the hosted
Studio into a fresh native release line so Windows and Android can be tested
against the same current application core before RC1.

This is primarily a cross-platform parity and regression-testing release. It
does not change the portable OMI manuscript format.

## Included changes

The beta includes the changes accumulated after 0.2.0-beta.3, including:

- the expanded cross-platform interface-language registry;
- the reorganized responsive header and manuscript navigation;
- personal multi-installation publishing credentials;
- WordPress and generic website/newsletter publishing with encrypted personal
  credentials, preview/approval and idempotent update semantics;
- mobile selection-toolbar and menu stabilization;
- live-publication page-boundary and page-footnote improvements;
- removal of the obsolete native-mobile bottom navigation bar;
- normal-editor document zoom from 50% to 200%, with a Word-style
  minus/slider/percentage/plus control and compact mobile magnifier trigger.

## Windows test target

The beta.4 Windows MSI and NSIS installers are intended to replace the older
desktop beta during manual testing. The test should verify that features already
seen in the hosted Studio are present in the native shell, especially:

- current responsive navigation and account layout;
- current manuscript editing and contextual menus;
- the Word-style document zoom control;
- current integrations and personal publishing credentials;
- WordPress/generic website publication configuration and preview flow;
- native open/save behavior and desktop update routing.

The release workflow performs an automated MSI install/uninstall round trip
before publishing the immutable Windows artifacts.

## Android test target

The native mobile shell no longer contains the old Document / Editor / Details
bottom navigation. Those functions are reached through the manuscript menu,
while Account remains in the persistent top row.

The editor uses the reclaimed viewport area and reserves only the operating
system bottom safe-area inset. The new document zoom control is collapsed to a
magnifier button on narrow mobile screens.

The checked-in Android versionCode floor is 1100. A new Android Release workflow
run derives a strictly higher code for the signed AAB and universal APK.

## Release gates

Before merge/tag/publication require green results for:

- OMI Studio CI/CD;
- 1.0 Readiness;
- CodeQL;
- PKP integration environment;
- Tauri Builds and Releases, including the Windows MSI round trip;
- iOS simulator smoke build.

After merge, the protected-main Tauri workflow creates the immutable
`v0.2.0-beta.4` native release. Android Play publication remains a separate
explicit Android Release workflow action.

## Compatibility

No OMI manuscript-format migration is required. The application release,
platform build numbers and OMI schema version remain independently versioned.
