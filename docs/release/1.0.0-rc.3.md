# Open Manuscript Studio 1.0.0-rc.3

Source preparation: **23 November 2026**. **Publication acceptance pending.**
NOT an independently certified release.

## Scope and changes

- Incorporates the [merged Office separation PR #971](https://github.com/open-manuscript-initiative/open-manuscript-studio/pull/971), so Studio no longer mounts the EuroOffice API or embeds the general-purpose Office editor on web/Windows/Linux/macOS/Android.
- EuroOffice continues as an independent external service. Studio retains native DOCX/ODT import/export and the OMI scholarly, semantic editing and publication model.
- Includes source-merged November improvements: dedicated live publication editor, print-page styles and running headers, cover/volume templates, rich footnotes and source citations, researched family trees/networks, and OJS/OMP publishing workflows.
- No automatic Office-content migration or destructive database deletion. Old trial-only Office database tables remain for a later audited cleanup.
- OMI portable file format remains **OMI-SPEC-320@0.3.0**; Draft specifications are not promoted to stable.
