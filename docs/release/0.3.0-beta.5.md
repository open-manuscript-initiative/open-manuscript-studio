# Open Manuscript Studio 0.3.0-beta.5

Date: 2026-10-09

## Source review and provenance

Beta.5 improves the checks and provenance retained when research material enters a manuscript:

- Review source information before adding imported references to the reference library or accepting DOCX/PDF manuscript conversion.
- Preserve a source or author-declared own-work origin for each imported visual object, while keeping private local filenames out of the visible manuscript.
- Keep OJS/OMP source attribution visible in editable manuscript projections.
- Allow source-backed research excerpts in additional safe module fields.

## Reading and study notes

The study-notes panel now sits at the bottom of the reading surface and shows only notes anchored to text currently visible in the manuscript viewport. The panel grows to the height it needs, up to half of the usable screen; overflow remains scrollable inside the panel, and the list follows the author as they scroll the manuscript.

## Platform diagnostics

On Android, the Help footer shows the platform versionCode alongside the shared Studio version.
