# Open Manuscript Studio 0.3.0-beta.8

Release preparation date: 2026-10-20. This release includes the merged DOCX title-import correction.

## DOCX import

When the manuscript title is repeated as the first numbered heading in a Word document, Studio recognizes that duplicate during both standard and large-document imports so the title is not shown twice. Other manuscript content continues through the import.
