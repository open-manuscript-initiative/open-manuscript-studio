# Open Manuscript Studio 1.0.0-rc.2

Source preparation: 11 November 2026. Publication acceptance pending.
NOT an independently certified release.

## Document menu layout

On desktop, the 12-column Document menu previously left the native Save and
cloud-backup cards in implicit single-column tracks. Long labels overflowed
very narrow buttons and left most of the row empty. Every panel now has an
explicit readable span. Native save and cloud-backup cards share half rows;
new-document and opening controls retain their balanced 7/5 split. Import
panels retain their three-column desktop layout. Saved documents span the full row.

Card text and action groups wrap when space is limited, keeping buttons sized
to their labels. Expanded cloud-backup controls stay below their toggle within
the same panel. The shared UI styles are bundled into web and native apps.

This candidate also packages the merged import-opening, working-role and DeepL
translation-suggestion improvements since the RC1 source preparation.

## Build and publication

Main-branch merges build the Windows, Linux, macOS and direct Android packages.
The signed Android AAB uses the separate Android Release workflow. Store MSIX
and experimental iOS builds remain separate workflows.

RC2 remains an opt-in prerelease. It must not replace the general updater's
latest stable release. The existing exact-SHA build evidence, artifact hashes,
E02 checks, 14 manual receipts and final Go/No-Go apply to this candidate too.
The existing #765, #770, #774 and #271 evidence/risk policies are retained; a
version increment does not record new physical-device or host acceptance.
RC1 observations remain historical and cannot certify RC2 binaries.
