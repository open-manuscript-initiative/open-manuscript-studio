# Open Manuscript Studio 0.3.0-beta.6

## Semantic source attribution

Externally imported visual objects now retain an explicit semantic link to the bibliographic record describing their source. After source review, Studio reuses a matching record or creates a provisional one. The source attribution remains distinct from a rendered citation, technical import provenance, and a private author declaration for previously authored work.

The portable manuscript format advances to OMI-SPEC-320@0.3.0. This pre-stable generation requires the sourceAttributions collection. Studio reports unsupported older file versions and does not migrate them silently.
