# Open Manuscript Studio 0.3.0-beta.13 — nine-stage consolidation

**Prepared 31 October 2026. Status: unreleased candidate, NOT an independently certified release.** Publication and store uploads require a separate owner Go/No-Go decision.

## Changes for users

Nine OMI-SPEC implementation stabilization stages (PRs #786, #788–#795) strengthen:
- Author-editable manuscript identities, structured sections/anchors/notes, versioning, validation and citation/reference integrity.
- Recursive nested publication rendering, portable OMI file/container and media-asset integrity.
- DOCX/ODT import preflight, safe editable candidate retention, export-file validity checks and explicit incomplete/loss reporting.
- Collaboration and peer-review authorization, translation rebase integrity, scoped API v1 extension manifest declarations, and conservative Draft capability/conformance self-assessments.

These changes **do not** establish full or independently verified OMI-SPEC conformance or promote any Draft to Stable. The manuscript format stays at **OMI-SPEC-320@0.3.0**.

- [ ] Open security issues [#765](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/765) (actual production outbound egress isolation), [#770](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/770) (restrictive native Tauri CSP and WebView permission review) and [#774](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/774) (untrusted PDF worker isolation) are implemented and tested **or** formally risk-accepted by the owner for a restricted distribution scope. No current PR proves production deployment security.
- [ ] Upstream GTK/glib alert [#271](https://github.com/open-manuscript-initiative/open-manuscript-studio/issues/271) is either fixed in the actual native dependency graph or logged as a limited external-dependency exception; it must not be mislabeled patched.
- [ ] Real private manuscript: DOCX import → freely edit and delete arbitrary content → save/close/reopen → OMI, DOCX and ODT export/reimport. Check notes, citations, media, cross-references, tables, language, large-document performance and source retained on failure.

- [ ] Windows installer upgrade, rollback/data preservation and Android signed AAB/APK update and versionCode tested on reference hardware. iOS distribution is experimental until signed device/TestFlight acceptance.
- [ ] Release artifact names and checksums verified after native builds; website release note/version switch **only after** the GitHub release is available.
