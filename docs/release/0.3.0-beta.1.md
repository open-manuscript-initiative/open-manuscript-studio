# Open Manuscript Studio 0.3.0-beta.1

Status: scholarly workflow and publication beta  
Date: 2026-09-24  
Next planned milestone: v1.0.0-rc.1

## Release purpose

0.3.0-beta.1 starts a new pre-1.0 feature line after the 0.2.0 cross-platform
stabilization betas. It groups the substantial authoring, publication-layout,
editorial-workflow and reference-management work completed after 0.2.0-beta.4
into one cross-platform release identity.

The portable OMI manuscript format remains independently versioned at
OMI-SPEC-320@0.2.0. The new optional bibliography-selection state is preserved
inside the existing portable model, so this application release does not require
a mandatory manuscript migration.

## Authoring and publication layout

- Adds section-level ruler support with tab stops, columns and text-to-table
  conversion for selected manuscript sections.
- Makes document zoom work consistently in both the HTML5 visual publication
  editor and print-layout mode.
- Adds an InDesign-compatible paragraph-style system and expands the style
  editor with the corresponding paragraph controls and live rendering.
- Improves desktop and mobile space usage throughout the Studio and makes short
  numeric/fixed-length form fields size to their expected content instead of
  occupying full-row width.

## Studio-native editorial workflow

- Adds Studio-native manuscript submission and editorial handling for journals
  and publishers that do not use OJS or OMP.
- Keeps OJS/OMP authoritative when those integrations are used, while the
  native workflow provides a self-contained alternative for other venues.
- Adds native peer-review assurance and revision-bound website publication
  metadata, including the OMI peer-review publication indication.
- Completes editor assignment persistence and the database migration required
  by the native editorial inbox.

## Reusable references and bibliography control

- Adds an authenticated personal reference library stored at account level so
  authors can reuse the same curated bibliographic records across manuscripts.
- Lets a document copy selected personal-library records into its own portable
  manuscript state, avoiding an online-account dependency when the file is
  reopened or exchanged.
- Adds per-document bibliography selection for uncited background works while
  cited records remain automatically included for referential integrity.
- Applies the same bibliography selection to HTML, JATS, custom exports and
  Studio-native review snapshots.

## Performance, localization and interface quality

- Reduces unnecessary work in the large live-publication editor while keeping
  source-state updates immediate.
- Applies additional multilingual translation coverage generated through the
  maintained supplemental translation workflow.
- Keeps the expanded reference-management and publication controls responsive
  on phone-sized layouts and extends browser regression coverage accordingly.

## Release gates

Before publication require green results for:

- OMI Studio CI/CD;
- 1.0 Readiness;
- CodeQL;
- PKP integration acceptance;
- Tauri desktop/mobile builds;
- iOS simulator smoke build.

The protected-main Tauri workflow creates the immutable
`v0.3.0-beta.1` release from the exact merged commit. Android Play publication
remains a separate explicit Android Release workflow action.

## Compatibility

Application, platform build and OMI document-format versions remain
independently versioned. Existing canonical OMI-SPEC-320@0.2.0 manuscripts do
not require a format migration for this release.
