# Open Manuscript Studio 0.3.0-beta.10

Release preparation: **24 October 2026**. This release improves responsiveness in the live publication editor for long manuscripts. Published historical releases remain immutable.

## What changes for users

- **Live publication editor:** measures print-layout manuscript blocks and footnotes in short, cancellable animation-frame chunks, keeping the interface responsive during pagination of long documents.
- **Portable format:** the OMI manuscript format remains `OMI-SPEC-320@0.3.0`.

## Updating and deployment

The [Studio downloads page](https://openmanuscript.org/studio/) follows the current published GitHub release. After the release PR is merged, native build workflows produce packages from the merged commit. Google Play requires a separate Android Release run from the merged `main`; its versionCode is derived from that run. iOS public distribution still requires Apple signing, provisioning and device/TestFlight validation.

No server migration is required.
