# Open Manuscript Studio 0.3.0-beta.7

Release preparation date: 2026-10-20. This beta packages the updates merged after
0.3.0-beta.6 into a new shared application version. Published beta.6 artifacts
remain immutable.

## Included updates

- **Android and EuroOffice:** system-navigation insets and a persistent editor
  host keep the embedded editor and its lower controls within the usable viewport.
  Compact floating controls leave more space for the document.
- **EuroOffice documents and recovery:** standalone office documents have
  recoverable save snapshots. Final saves are bound to the opening revision;
  duplicate or late callbacks cannot overwrite a newer document head.
- **Transkribus:** connect a personal account, browse recognition models by name,
  language or creator, recognize one page image after explicit credit consent,
  and review/correct the transcription before inserting it with source and rights
  metadata. Durable request identities prevent automatic resubmission of unknown
  paid requests; this is not a guarantee of exactly-once provider billing.
- **ODT (Preview):** import/export headings, basic formatting, lists, tables,
  notes and supported images, with bounded archive validation and explicit
  warnings for source relationships that ODT cannot preserve.
- **Localization and layout:** PO-backed labels, production research-module
  translation loading, wrapping language choices and compact desktop settings.
- **Accounts and editor selection:** browser passkeys where configured, and a
  simpler choice of OMI, visual publication and EuroOffice workflows. Native
  passkey handoff remains unsupported.
- **Maintenance:** merged Tauri and server dependency updates are included.

## Deployment and distribution

1. Back up both application and identity databases and close active EuroOffice
   sessions, allowing their final callbacks to finish.
2. From `server/`, apply pending migrations with
   `npm run prisma:migrate:deploy` and `npm run prisma:migrate:identity:deploy`.
   These include passkeys, standalone EuroOffice documents and integration
   execution/recovery records. Regenerate both Prisma clients when building
   the API (`npm run build` does this).
3. Deploy the API before the frontend/native clients. Reopen EuroOffice sessions
   after deployment: old unbound sessions are expired by the migration. Follow
   the [external integration deployment/rollback instructions](../architecture/external-integration-boundaries.md).
4. Merge this release change into `main`. The Tauri release workflow builds the
   new Windows, Linux, macOS and Android APK assets; promotion updates `latest`
   only after verifying their exact tagged build commit. Existing release assets
   are not replaced. iOS distribution still requires signing/provisioning and
   device/TestFlight validation.
5. For Google Play, start a **new** Android Release workflow run from the merged
   `main` with `publish_to_play: true` and the intended testing track. The workflow
   derives a higher run-specific versionCode from offset 1200. Do not rerun an
   already uploaded run as a new upload. The shared APK release does not upload
   an AAB to Google Play.

## Validation

CI build, test and portable-format conformance results are the release evidence.
Real EuroOffice recovery, Transkribus credits/network reconciliation and native
device acceptance remain required before promoting these integrations to Stable.
