# Open Manuscript Studio 1.0.0-rc.4

Source preparation: **25 November 2026**. **Publication acceptance pending.**
NOT an independently certified release.

## Scope

- Includes the merged November formatting and publication work, formatted note hover and keyboard focus previews (#1041), and memory-backed editor projections (#1042) integrated into adaptive memory management (#1043).
- Shared derived-cache budget, selectable modes, diagnostics, background eviction and Android system-memory sampling. The estimated cache budget is not total application RAM. Actual WebView PSS, low-memory behavior and 50/100/250/500/1000-page performance measurements are pending; provisional 3 GiB minimum and 6 GiB recommended Android RAM are not certified requirements.
- Retain manuscript and undo history, DOCX/ODT and PKP workflows, independent EuroOffice service, Draft specifications and **OMI-SPEC-320@0.3.0**.
