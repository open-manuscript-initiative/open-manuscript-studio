# Open Manuscript Studio 0.3.0-beta.9

Release preparation: **24 October 2026**. This release packages the merged Linux deep-link correction and Dutch and Polish translations. Published historical releases remain immutable.

## What changes for users

- **Linux deep links:** registration and lookup now report I/O failures clearly. Unregistration removes this app's MIME association while preserving associations belonging to other applications.
- **Translations:** includes the returned Dutch and Polish translations across the shared Studio interface and research modules.
- **Portable format:** the OMI manuscript format remains `OMI-SPEC-320@0.3.0`.

## Updating and deployment

The [Studio downloads page](https://openmanuscript.org/studio/) follows the current published GitHub release. After the release PR is merged, native build workflows produce packages from the merged commit. Google Play requires a separate Android Release run from the merged `main`; its versionCode is derived from that run. iOS public distribution still requires Apple signing, provisioning and device/TestFlight validation.

This release includes a Linux deep-link integration correction and translations; no server migration is required.
