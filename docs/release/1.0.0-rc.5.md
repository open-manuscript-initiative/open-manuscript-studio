# Open Manuscript Studio 1.0.0-rc.5

Source preparation: **26 November 2026**. **Publication acceptance pending.**
NOT an independently certified release.

## Scope

- Includes RC4 and the merged #1070 optimization work, #1083 OJS issue foundations and #1088 complete planned-issue workflow consolidation.
- Import an ordered unpublished OJS issue as an editable Studio journal issue with article metadata, source documents, notes, section provenance, progress, template suggestions and non-destructive reimport review.
- Render a single issue PDF through the isolated worker; review physical article ranges, extract article PDFs without reflow, export article HTML and JATS Article Authoring XML, stage and explicitly confirm issue-bound transfers, and separately review and write printed page labels.
- Article DOI metadata requires the compatible OJS plugin 1.9.1 (including #49). No automatic publication, no JATS Publishing tag-set certification, and no PDF XMP enhancement. Live OJS editorial acceptance remains pending.
- Retain Draft specifications and **OMI-SPEC-320@0.3.0**. Prior device memory, latency and release acceptance evidence is not inherited.

## Coordinated rollout

1. Run exact-SHA Studio CI/CD, CodeQL, native Tauri builds, PKP integration, OMI conformance, 1.0 readiness and signed Android checks.
2. Deploy the compatible Studio frontend/API and isolated PDF worker together; configure OJS issue launch/progress/handoff routes. Install and verify qpdf and Poppler on the worker host; follow the [worker rollout](../server/pdf-worker-systemd-rollout.md).
3. After the OJS plugin 1.9.1 release passes native compatibility and packaging checks, back up the existing OJS plugin/settings and upgrade using its published TAR.GZ. Verify the installed version and retained settings. Test an unpublished issue in staging before using production.
4. Verify ordered import, identifiers, formatted notes, reimport, physical versus printed page ranges, artifact provenance and manual OJS approval. Do not publish a test issue. Review uncertain writes in OJS before retrying.
5. Verify install/update, document preservation and physical-device performance; review blockers #765, #770, #774 and #271. Record artifact SHA256, all 14 manual RC receipts, E02 evidence and explicit owner **Go/No-Go** for this exact SHA.
6. Publish `v1.0.0-rc.5` only through the protected Tauri Builds and Releases dispatch with `candidate_only=false`, exact `release_reviewed_sha`, `release_build_run_id`, complete `release_evidence_json` and `release_approval=APPROVE_1_0_RELEASE`. Preserve prerelease status; do not replace the public stable updater target.
