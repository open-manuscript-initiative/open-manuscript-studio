# Insert menu behavior

The continuous manuscript surface does not render insertion controls between paragraphs or blocks.

Visual and imported elements are inserted from the Studio header **Insert** menu. In the current transitional block-based editor, the insertion target is the end of the selected section. When the manuscript is consolidated into a single Tiptap document, this target should be replaced by the exact editor cursor/block position.

This keeps the authoring surface visually continuous while preserving the existing OMI section/block model during the migration.
