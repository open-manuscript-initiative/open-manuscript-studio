# Volumes, journal issues and publication identifiers

Choose **New volume or issue**, then choose **Volume** or
**Journal issue** in the creation form. Monographs also use the publication
metadata form. A journal issue uses independent studies and per-study notes.

All identifier fields are optional and available for both publication types:
print ISBN, electronic ISBN, print ISSN, electronic ISSN (eISSN), DOI of the
whole publication, and other identifiers such as ARK or URN. Journal issues
show ISSN fields first; volumes show ISBN fields first. Changing the type
preserves all entered values. ISBN and ISSN can be supplied together, including
for special issues and books published in series. Put multiple identifiers
in the same category on separate lines.

Identifiers remain editable under **Title matter**. The **Fill from publication
metadata** action on the imprint page includes every supplied identifier.
Existing manually edited imprint text is replaced only when that action is
used. The publication-level DOI is separate from individual study metadata.

The publication type and identifiers are included in the initial revision and
preserved by OMI save/open. An identifier is recorded as metadata; entering it
does not register it with an identifier agency.
