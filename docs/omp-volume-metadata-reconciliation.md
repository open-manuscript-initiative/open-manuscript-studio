# OMP volume metadata reconciliation (Preview)

An imported OMP volume with exact installation/press/submission/publication provenance exposes a separate volume metadata panel. Choose a personal OMP connection, inspect the exact native publication, select language and fields, and confirm one direction. Title, subtitle, abstract and keywords only; secondary-language title/subtitle are disabled where the local model cannot represent them. Existing chapter content, identifiers, series and other locales are not overwritten. Abstract transfer uses plain text. No automatic retries after uncertain writes; inspect the native publication. The Studio route `/api/v1/integrations/connections/:connectionId/omp-metadata` requires session, native per-installation credentials, explicit OMP capability, current IDs and bound receipts. Requires the OMP plugin containing #32; native production acceptance and release evidence are pending. Generic OJS metadata/workflow routes are unchanged.
