# Stabilization phase 4: OMI-SPEC-220 / 210 / 221 / 225

Status: **Draft implementation evidence, not a specification lifecycle promotion.**

This phase follows the agreed nine-stage stabilization order: bibliographic
records (220), semantic citation occurrences (210), personal/manuscript
reference libraries and interchange (221), and source/derivation links (225).

The documented citation ↔ reference-library dependency cycle is handled as
one coordinated group, not as two independent standards promotions.

## Evidence collected

| Contract | Observation and regression check | Limit |
| --- | --- | --- |
| OMI-SPEC-220 bibliographic identity | Different explicit DOIs are never treated as one work merely because title, author and date agree. Existing exact normalized DOI matches are retained. | Edition/retraction relationship resolution needs independent provider evidence. |
| OMI-SPEC-221 library reconciliation | Bulk import only drops a distinct local-ID input when the DOI match is confirmed; uncertain similarities stay in the manuscript and can be reviewed. No external provider is a single point of authority. | Human conflict-resolution UI and provenance merge remain incomplete. |
| OMI-SPEC-210 occurrence identity and anchoring | Legacy single-citation helpers now walk embedded sections and child blocks. Citation-derived label edits in these blocks get semantic block.content change events rather than silently missing the revision log. | Cross-implementation round trips and every citation style are not certified. |
| OMI-SPEC-225 source relationships | Existing source-attribution references remain separately identified, do not automatically become citations or licences, and are reported as lossy on HTML/JATS/ODT output. Import de-duplication must not silently conflate distinct works that these relationships may target. | This patch does not introduce source-relationship merge/retarget operations; unresolved identities require explicit reconciliation. |

## Safety gates

- No automatic reassignment of citation targets, source-attribution targets,
  author-confirmation status or bibliographic ownership.
- No change to manuscript prose, non-editable spans, anonymous review policy,
  public visibility, schema versions or application release versions.
- Reference records without exact DOI evidence are preserved, possibly
  creating probable duplicates; this is intentional to avoid destructive
  scholarly identity guesses.
- Positive and negative regression tests cover conflicting DOIs, independent
  local IDs, nested anchors, nonmutating citation transformations and
  complete nested block-history change events.
- All mandatory CI and security checks, large-manuscript performance,
  manual source-attribution/privacy review, version-pinned fixtures, public
  normative review and independent interoperability evidence remain required.
- Phases 5–9 still remain; **version bump occurs only after all nine phases
  have passed their gates**, and only with explicit release approval.

Neither this PR nor the existing Studio test suite is proof of full
OMI-SPEC-210/220/221/225 conformance. The normative models remain Draft.
