# IDML table import

Use Insert element → Import and choose an `.idml` file. This imports native tables as editable OMI visual blocks, not a whole InDesign manuscript. Tables are extracted in designmap story-reference order, with nested tables retained inside their containing cell. The existing source-attribution preview and confirmation remain active. The existing IDML publication-style import is unchanged.

The importer reads column:row coordinates, rejects overlap, missing anchors and invalid header-crossing spans, and materializes supported table/cell/paragraph/character style inheritance as validated OMI properties. It maps relative column widths, row minimum/exact heights, repeated headers, supported cell rotation, vertical alignment, insets, RGB fills and stroke properties. Paragraph and character overrides are converted to rich cell documents. Source file and story provenance are retained.

Limits: the visual-import file quota, existing bounded ZIP reader, 10,000 cells across the package and four nested levels. DTD/entity declarations and invalid story references are rejected. No external resources are fetched. Unsupported swatches, footer roles, native note projections and some style or content features raise warning codes and a localized partial-fidelity notice. CMYK swatches other than built-in black, color tints, custom stroke patterns, complex parent-counter numbering, links and graphical cell objects are not faithfully imported. Native ordered and bullet paragraphs are reconstructed as editable OMI lists, including inherited paragraph-style settings, supported numbering formats, level, start/restart, current-level marker expression, Unicode bullets and list indentation. The importer groups contiguous list items and nests increasing levels under the preceding item, without creating artificial parent items. An explicit NoList paragraph with a matching local AppliedNumberingList reference is attached to its list item; ordinary paragraphs remain ordinary paragraphs. Repeated named sequences within a cell preserve known continuation counts. Cross-cell/story continuation, compound parent-counter expressions, missing parent levels, unsupported marker styles and glyph-only bullets produce partial-fidelity warnings rather than inferred exact numbering. NoList paragraphs with no structural list reference, literal fallback labels and note labels remain text. Generated list labels are never inserted into the text matrix. Named styles are flattened; full manuscript, layout, graphics, pagination and publication-template import are outside this feature.

Regression tests inspect Studio IDML export/import geometry, nested content order, rich text, style inheritance, and rejection of invalid geometry, DTDs and unsafe story paths. They are not proof of interoperability with all third-party InDesign packages. Verify imported tables before publication.
