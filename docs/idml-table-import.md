# IDML table import

Use Insert element → Import and choose an `.idml` file. This imports native tables as editable OMI visual blocks, not a whole InDesign manuscript. Tables are extracted in designmap story-reference order, with nested tables retained inside their containing cell. The existing source-attribution preview and confirmation remain active. The existing IDML publication-style import is unchanged.

The importer reads column:row coordinates, rejects overlap, missing anchors and invalid header-crossing spans, and materializes supported table/cell/paragraph/character style inheritance as validated OMI properties. It maps relative column widths, row minimum/exact heights, repeated headers, supported cell rotation, vertical alignment, insets, RGB fills and stroke properties. Paragraph and character overrides are converted to rich cell documents. Source file and story provenance are retained.

Limits: the visual-import file quota, existing bounded ZIP reader, 10,000 cells across the package and four nested levels. DTD/entity declarations and invalid story references are rejected. No external resources are fetched. Unsupported swatches, footer roles, native note projections and some style or content features raise warning codes and a localized partial-fidelity notice. CMYK swatches other than built-in black, color tints, custom stroke patterns, native numbering, links and graphical cell objects are not faithfully imported. Native IDML list paragraphs currently import as ordinary paragraphs with a `native-list-structure-not-imported` warning. Generated list labels are not part of the source text and are not reconstructed. Literal fallback labels and note labels remain text; no semantic note or list relationship is inferred. Named styles are flattened; full manuscript, layout, graphics, pagination and publication-template import are outside this feature.

Regression tests inspect Studio IDML export/import geometry, nested content order, rich text, style inheritance, and rejection of invalid geometry, DTDs and unsafe story paths. They are not proof of interoperability with all third-party InDesign packages. Verify imported tables before publication.
